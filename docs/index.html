How it works

Five kinds of agent, one room, and rights that Switch enforces, not prompts.

1 · AskThe lead types @swarm-foreman sweep in Slack, Teams, Discord or Mattermost.
2 · PlanThe foreman scans every repo and hands one to each worker, one thread per repo.
3 · FixWorkers upgrade, fix what breaks, test, and post a patch file. They never push.
4 · VerifyA rival-vendor verifier re-runs every patch from scratch and hunts for faked fixes.
5 · ShipThe gate asks the lead once, then opens the PRs and merges them.
Foreman

Plans and tracks

Read-only GitHub. Notices silence and reassigns stalled work.

Workers

Do the fixing

Codex, OpenCode or Claude. Read-only GitHub, so a poisoned changelog has nothing to misuse.

Verifier

Trusts nothing

A different vendor. Tests the exact patch by its SHA-256, on a clean clone.

Gate

Only one who writes

The only write grant. Only the lead can command it, so only the lead can approve its card.

Green tests are not proof

On orders-api, upgrading jsonwebtoken to 9 breaks sign-in because the dev keys are 1024-bit. Two patches both turn the tests green and the scan clean. Only one is a fix.

Use it on your repos

Nothing is installed in your repositories or CI. You need a Switch server, a machine for the agents, and ten minutes.

  1. Run SwitchSelf-host the Switch server (Docker), or use the local server Switch Console sets up. Turn on agent management.
  2. Connect your toolsInstall Switch Console on the machine the agents run on and sign in two agent CLIs from different vendors (say Claude Code and Codex). Connect Slack, Teams, Discord or Mattermost, and install the Switch GitHub App on your repositories.
  3. Describe your fleet and build the templateList your repos and providers, then generate one Switch template for the whole swarm. 
    git clone https://github.com/hassaansaleem28/backlog-swarm && cd backlog-swarm
cp fleet.example.yml fleet.yml        # your repos, your providers
uv run scripts/build_template.py fleet.yml > swarm.template.yaml
  4. Create the swarmIn Switch Console: Templates → New → paste → Use template. One click creates the room and every agent.
  5. Talk to itFrom your team chat: 
    @swarm-foreman sweep
@swarm-foreman status
@swarm-gate ship it

Why Switch is the product, not a detail

Many vendors, one room

Codex builds, Claude verifies, in the chat your team already uses. No single vendor ships this.

Rights the server enforces

Who may command which agent, and who may answer its approval card, is configuration, not a prompt.

Credentials agents never hold

Short-lived GitHub tokens scoped to the fleet: read for the swarm, write for the gate only.
